## Vector Norms 
### Vector p-norms
**Definition (Vector norm)**

A **vector norm** on $\mathbb{R}^n$ is a function

$$
\|\cdot\| : \mathbb{R}^n \to \mathbb{R}
$$

satisfying:

1. $\|x\| \geq 0$ for all $x \in \mathbb{R}^n$, and $\|x\| = 0$ iff $x = 0$.
2. $\|x + y\| \leq \|x\| + \|y\|$ for all $x, y \in \mathbb{R}^n$. This is the **triangle inequality**.
3. $\|\alpha x\| = |\alpha|\|x\|$ for all $\alpha \in \mathbb{R}$ and $x \in \mathbb{R}^n$.

For $x \in \mathbb{R}^n$ and $p \geq 1$, the **$p$-norms** are defined by

$$
\|x\|_p = \left( \sum_{i=1}^{n} |x_i|^p \right)^{\frac{1}{p}}.
$$

The most important being 1-norm, 2-norm and $\infty$-norm (maximum norm)

### Equality of vectors

Let $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$. Then:

- $\mathbf{x} = \mathbf{y} \Longleftrightarrow x_i = y_i$ for all $i = 1, \ldots, n$.
- $\mathbf{x} = \mathbf{y} \Longleftrightarrow \|\mathbf{x} - \mathbf{y}\| = 0$.
- In MATLAB, `x == y` is a logical array. In Python, `x == y` is a Boolean array.
- With rounding error, two vectors are treated as equal if

$$
\|\mathbf{x} - \mathbf{y}\| \leq \tau(\epsilon, n, \|\mathbf{x}\|, \|\mathbf{y}\|).
$$

### Error in vectors

If $\bar{\mathbf{x}} \in \mathbb{R}^n$ is a computed approximation to $\mathbf{x} \in \mathbb{R}^n$, then:

- The **absolute error** is

$$
e_a = \|\bar{\mathbf{x}} - \mathbf{x}\|.
$$

- The **relative error**, for $\mathbf{x} \neq 0$, is

$$
e_r = \frac{\|\bar{\mathbf{x}} - \mathbf{x}\|}{\|\mathbf{x}\|}.
$$

- The largest component of $\mathbf{x}$ has $k$ significant figures if

$$
\frac{\|\bar{\mathbf{x}} - \mathbf{x}\|_{\infty}}{\|\mathbf{x}\|_{\infty}}
< 0.5 \times 10^{-k}.
$$

Thus, the number of significant figures can be estimated as

$$
k = \left\lfloor
-\log_{10}\left(
2\frac{\|\bar{\mathbf{x}} - \mathbf{x}\|_{\infty}}{\|\mathbf{x}\|_{\infty}}
\right)
\right\rfloor.
$$

## Matrix Norm
**Definition (Matrix norm)**

A **matrix norm** is a scalar function

$$
\|\cdot\| : \mathbb{R}^{m \times n} \to \mathbb{R}
$$

satisfying:

1. $\|A\| \geq 0$ for all $A \in \mathbb{R}^{m \times n}$, and $\|A\| = 0 \Longleftrightarrow A = 0$.
2. $\|A + B\| \leq \|A\| + \|B\|$ for all $A, B \in \mathbb{R}^{m \times n}$. This is the **triangle inequality**.
3. $\|\alpha A\| = |\alpha|\|A\|$ for all $\alpha \in \mathbb{R}$ and $A \in \mathbb{R}^{m \times n}$.

**Definition (Consistent matrix norms)**

Matrix norms are **consistent** if

$$
\|AB\| \leq \|A\|\|B\|
$$

for all $A \in \mathbb{R}^{m \times n}$ and $B \in \mathbb{R}^{n \times \ell}$.

### Common matrix norms

The **subordinate matrix $p$-norm** is defined in terms of vector norms by

$$
\|A\|_p
=
\max_{\mathbf{x} \neq 0}
\frac{\|A\mathbf{x}\|_p}{\|\mathbf{x}\|_p},
\qquad
p = 1, 2, \ldots
$$

From this definition, if  
$A \in \mathbb{R}^{m \times n}$, $\mathbf{x} \in \mathbb{R}^n$, and $\mathbf{x} \neq 0$, then

Note that **subordinate matrix p-norms are consistent**.

$$
\|A\mathbf{x}\|_p
=
\frac{\|A\mathbf{x}\|_p}{\|\mathbf{x}\|_p}
\|\mathbf{x}\|_p
\leq
\|A\|_p \|\mathbf{x}\|_p.
$$

The **Frobenius matrix norm** is defined by

$$
\|A\|_F
=
\left(
\sum_{i=1}^{m}
\sum_{j=1}^{n}
|a_{ij}|^2
\right)^{\frac{1}{2}}.
$$

The Frobenius norm is **not** the same as the subordinate matrix $2$-norm, $\|A\|_2$.

Common subordinate matrix $p$-norms use $p = 1, 2,$ and $\infty$.

- MATLAB: `norm`
- Python: `numpy.linalg.norm`

```matlab
norm(A, 2)      % 2-norm
norm(A, 1)      % 1-norm
norm(A, inf)    % infinity-norm
norm(A, 'fro')  % Frobenius norm
```
### Important subordinate matrix norms
The matrix **$1$-norm** is the maximum absolute column sum, that is 

$$
\max_{\mathbf{x} \neq 0}
\frac{\|A\mathbf{x}\|_1}{\|\mathbf{x}\|_1}
=
\max_{1 \leq j \leq n}
\sum_{i=1}^{m} |a_{ij}|.
$$

The matrix **$\infty$-norm** is the maximum absolute row sum, that is

$$
\max_{\mathbf{x} \neq 0}
\frac{\|A\mathbf{x}\|_\infty}{\|\mathbf{x}\|_\infty}
=
\max_{1 \leq i \leq m}
\sum_{j=1}^{n} |a_{ij}|.
$$

**Matrix 2-norm**

For $A \in \mathbb{R}^{m \times n}$,

$$
\|A\|_2 = \sqrt{\lambda_{\max}(A^T A)}.
$$

This works because $A^T A$ is always symmetric positive semidefinite, so
its eigenvalues are real and non-negative.

Important: these are eigenvalues of $A^T A$, not necessarily eigenvalues
of $A$ itself. For a square matrix $A$,

$$
\|A\|_2
\neq
\max_i |\lambda_i(A)|
$$

in general.

They are equal in special cases such as real symmetric matrices, where

$$
\|A\|_2 = \max_i |\lambda_i(A)|.
$$

### Equality of matrices

Let $A = [a_{ij}]$ and $B = [b_{ij}]$ be two matrices in
$\mathbb{R}^{m \times n}$. Then:

- $A = B \Longleftrightarrow a_{ij} = b_{ij}$ for all
  $i = 1, \ldots, m$ and $j = 1, \ldots, n$.
- $A = B \Longleftrightarrow \|A - B\| = 0$.
- In MATLAB, `A == B` returns a logical array. In Python, `A == B`
  returns a Boolean array.
- With rounding error, two matrices are treated as equal if

$$
\|A - B\| \leq \tau(\epsilon, m, n, \|A\|, \|B\|),
$$

where $\tau$ is a tolerance depending on the machine precision $\epsilon$,
the dimensions $m,n$, and the norms of $A$ and $B$.

## Condition Numbers

For any nonsingular matrix $A \in \mathbb{R}^{n \times n}$, the
**condition number** is

$$
\kappa(A) = \|A\|\|A^{-1}\|,
$$

where $\|\cdot\|$ is any matrix norm.

For a consistent matrix norm with $\|I_n\| = 1$,

$$
I_n = AA^{-1}
\quad \Longrightarrow \quad
1 = \|I_n\| = \|AA^{-1}\| \leq \|A\|\|A^{-1}\|
\quad \Longrightarrow \quad
\kappa(A) \geq 1.
$$

Useful facts:

- $\kappa(\alpha I_n) = 1$ for $\alpha \in \mathbb{R}$, $\alpha \neq 0$.
- A larger $\kappa(A)$ means the solution $x$ of $Ax = b$ is more sensitive
  to small errors in the data.
- $A$ is **ill-conditioned** if $\kappa(A)$ is large. A common rule is
  $\kappa(A) > 1/\epsilon \approx 10^{16}$, where $\epsilon$ is relative
  machine precision.

For a real symmetric nonsingular matrix $A$ with eigenvalues
$\lambda_1, \ldots, \lambda_n$, using the $2$-norm,

$$
\kappa_2(A)
= \|A\|_2\|A^{-1}\|_2
=
\frac{\max_{1 \leq i \leq n} |\lambda_i|}
{\min_{1 \leq i \leq n} |\lambda_i|}.
$$

The **reciprocal condition number** is

$$
0 < \operatorname{rcond}(A) = \frac{1}{\kappa(A)} \leq 1.
$$

- Well-conditioned $\Longleftrightarrow \operatorname{rcond}(A)$ is close to $1$.
- Badly conditioned $\Longleftrightarrow \operatorname{rcond}(A)$ is close to $0$.

MATLAB and Python:

- MATLAB `cond(A, p)` and Python `numpy.linalg.cond(A, p)` use the
  $p$-norm for $p = 1, 2, \infty$.
- MATLAB `rcond(A)` gives an estimate of $1/\kappa(A)$ using the $1$-norm.

Python example:

```python
A = array([[1.0, 1.0],
           [1.0, 1.0001]])

b = array([2.0, 2.0001])
b2 = array([2.0, 2.00010001])   # tiny change in b

x = solve(A, b)
x2 = solve(A, b2)

print(x)        # [1. 1.]
print(x2)       # [0.9999 1.0001]
print(cond(A))  # 40002.00029797418
```

The small change from $b$ to $b_2$ can cause a much larger change from $x$ to $x_2$ because $A$ is ill-conditioned.

### Perturbations in Linear Systems

Let $A$ be nonsingular. We want to understand how errors in the data $A$ and $b$ affect the computed solution of

$$
Ax = b.
$$

A **perturbed system** means the original system has been changed slightly because of errors or noise in the data. The perturbed system is

$$
(A + \delta_A)(x + \delta_x) = b + \delta_b,
$$

where $A + \delta_A$ is assumed to be nonsingular.

Here, $\delta_x$ is the change in the solution $x$ due to changes $\delta_A$ and $\delta_b$ in the matrix $A$ and vector $b$, respectively.

The relative errors in the input data are

$$
\rho_A
=
\frac{\|(A + \delta_A) - A\|}{\|A\|}
=
\frac{\|\delta_A\|}{\|A\|},
\qquad
\rho_b
=
\frac{\|\delta_b\|}{\|b\|}.
$$

The relative error in the solution is denoted by $\rho_x$. Then the relative error in the solution is bounded by

$$
\rho_x
=
\frac{\|(x + \delta_x) - x\|}{\|x\|}
=
\frac{\|\delta_x\|}{\|x\|}
\leq
\alpha \kappa(A)(\rho_b + \rho_A).
$$

### Well-conditioned and ill-conditioned systems

Let $A \in \mathbb{R}^{n \times n}$ be nonsingular. The linear system
$Ax = b$ is **well-conditioned** if a small change in $A$ or $b$ leads to
only a small change in $x$.

The linear system $Ax = b$ is **ill-conditioned**, or **badly
conditioned**, if a small change in $A$ or $b$ can result in a large change
in $x$. Then we expect trouble when computing $x$ numerically.

The matrix $A$ is **well-conditioned** if $Ax = b$ is well-conditioned for
every $b$.

The matrix $A$ is **ill-conditioned** if $Ax = b$ is ill-conditioned for
some $b$.
